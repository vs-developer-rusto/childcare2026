Политика конфиденциальности
Приложение «Пособие до 1,5 лет 2026» (ru.svp.childcare2026)

Редакция от 25.10.2026

1. Общие положения

1.1. Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного приложения «Пособие до 1,5 лет 2026» (далее — Приложение) для Android.

1.2. Связь по вопросам персональных данных и конфиденциальности: vs_developer@inbox.ru.

1.3. Используя Приложение, вы подтверждаете, что ознакомились с настоящей Политикой. Если вы не согласны с условиями, пожалуйста, не используйте Приложение.

1.4. Приложение предназначено для ориентировочного расчёта ежемесячного пособия по уходу за ребёнком до 1,5 лет для работающего застрахованного родителя (отпуск по уходу, начавшийся в 2026 году). Расчёт выполняется на устройстве пользователя. У Приложения нет собственной регистрации, аккаунтов и облачного сервера для хранения ваших расчётов.

1.5. Приложение не является государственным сервисом, не представляет Социальный фонд России, Минтруд или работодателя и не назначает пособие. Окончательный размер выплаты определяет СФР.

2. Какие данные обрабатываются

2.1. Данные, которые вы вводите для расчёта (например, доход за 2024 год, доход за 2025 год, число исключаемых календарных дней).
Эти данные используются только для расчёта на вашем устройстве. Оператор не получает их на свой сервер и не хранит их вне вашего устройства.

2.2. История последних расчётов.
История сохраняется локально на устройстве (без облака и без аккаунта). Вы можете удалить отдельные записи средствами Приложения (например, свайпом в списке истории), очистить всю историю в меню Приложения или удалить/очистить данные Приложения в системе Android.

2.3. Данные для показа рекламы.
В Приложении может использоваться рекламная сеть Яндекс.Реклама (баннер и межстраничная реклама, как правило после экрана результата). Рекламный SDK может самостоятельно получать технические данные устройства, необходимые для показа и учёта рекламы (в том числе рекламный идентификатор устройства и иные технические параметры по правилам SDK). Обработка таких данных регулируется политикой конфиденциальности Яндекса:
https://yandex.ru/legal/confidential/

2.4. Список других приложений линейки.
Для блока «Другие приложения» / ссылки на соседние калькуляторы Приложение может один раз за запуск загрузить публичный JSON-список продуктов (например, с GitHub Pages). В этот запрос не передаются суммы доходов, число дней, рассчитанное пособие и иные введённые вами данные — только обычный сетевой запрос к публичному файлу.

2.5. Покупки внутри Приложения.
Если вы оформляете покупку «убрать рекламу» через RuStore или Google Play, платёжные данные обрабатываются соответствующим магазином приложений. Оператор не получает и не хранит данные банковских карт.

2.6. Обращения в поддержку.
Если вы пишете на vs_developer@inbox.ru, обрабатываются адрес электронной почты и содержание обращения — только для ответа на ваш запрос.

3. Цели обработки

- выполнение расчёта на устройстве пользователя;
- хранение локальной истории расчётов;
- показ рекламы и измерение её эффективности (через рекламный SDK);
- отображение ссылок на другие приложения линейки;
- обработка покупок через магазин приложений;
- ответ на обращения в поддержку.

4. Передача данных третьим лицам

4.1. Оператор не продаёт персональные данные и не передаёт введённые вами суммы и параметры расчёта на собственный сервер.

4.2. Третьи стороны, которые могут обрабатывать технические данные в связи с работой Приложения:
- Яндекс (реклама) — при наличии рекламы в установленной версии;
- хостинг публичного JSON линейки (например GitHub Pages) — только для загрузки списка приложений;
- VK / RuStore и/или Google Play — при установке, обновлении и покупках через магазин.

4.3. Оператор может раскрыть информацию, если это требуется по закону Российской Федерации или по запросу уполномоченного органа в установленном порядке.

5. Хранение и безопасность

5.1. Данные расчётов и история хранятся на вашем устройстве. Срок хранения истории определяется вами (удаление записей или данных Приложения).

5.2. Оператор не контролирует безопасность вашего устройства. Рекомендуется использовать актуальные обновления ОС и не предоставлять устройство посторонним лицам без необходимости.

6. Данные детей

Приложение предназначено для взрослых пользователей (родителей и иных лиц, оформляющих отпуск по уходу) и не предназначено для сбора персональных данных детей. Приложение не ориентировано на лиц младше 13 лет и не собирает сведения о ребёнке (ФИО, дату рождения и т.п.). Если вы считаете, что ребёнок передал нам данные через обращение на email, напишите на vs_developer@inbox.ru — обращение будет удалено.

7. Ваши права

Вы можете:
- не вводить данные, которые не хотите указывать;
- удалить локальную историю в Приложении или через настройки Android («Очистить данные» / удаление Приложения);
- отключить персонализацию рекламы в настройках Android (рекламный идентификатор), если такая опция доступна на устройстве;
- написать на vs_developer@inbox.ru с вопросом об обработке данных.

8. Изменение Политики

Оператор может обновлять настоящую Политику. Актуальная редакция публикуется по адресу Политики конфиденциальности, указанному в карточке Приложения в магазине (в том числе в Google Play). Дата редакции указана в начале документа.
